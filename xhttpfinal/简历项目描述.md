# 简历项目描述 - C++ HTTP服务器

## 项目概述

**基于C++11的高性能多线程HTTP服务器**

开发了一个完整的HTTP服务器，支持静态文件服务和PHP动态内容处理，深入实践了网络编程、并发处理和协议实现等核心技术。

## 技术栈

- **编程语言**: C++11
- **构建工具**: Makefile
- **网络编程**: BSD Socket API
- **操作系统**: Linux
- **并发模型**: epoll I/O多路复用 + 多线程
- **动态内容**: PHP-CGI集成

## 核心架构设计

### 系统架构
- 采用**Reactor事件处理模型**，通过epoll实现高效的I/O多路复用
- 实现**主从线程架构**：主线程负责连接监听，工作线程处理业务逻辑
- 模块化设计，分离网络通信、协议解析、业务处理等核心功能

### 关键技术实现
- **HTTP/1.1协议完整实现**：通过正则表达式精确解析请求行和头部字段
- **动态内容支持**：集成PHP-CGI，实现动态脚本执行和结果返回
- **静态文件服务**：高效的文件I/O操作和分块传输机制
- **完善的错误处理**：支持HTTP 400、404、405、500等状态码

## 主要技术成果

### 性能优化
- 实现**线程池技术**，有效利用多核CPU资源，提升并发处理能力
- 采用**非阻塞I/O**和**事件驱动**模型，减少系统资源消耗
- 优化内存管理，实现高效的文件缓存和传输机制

### 协议实现深度
- 完整实现**HTTP GET方法**，支持路径解析和查询参数处理
- 精确处理**HTTP头部字段**，包括Content-Type、Content-Length、Server等
- 实现**标准CGI接口**，与PHP解释器无缝集成，支持动态内容生成

### 工程实践能力
- 编写**自动化构建脚本**(Makefile)，支持调试模式和发布模式
- 进行**模块化重构**，提高代码可维护性和可扩展性
- 实施**系统级调试**，深入理解网络协议栈和操作系统机制
